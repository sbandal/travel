# Travel Plans

Collection of interactive trip planners hosted on GitHub Pages (`https://sbandal.github.io/travel/`).

## Trips
- **Oʻahu, Hawaiʻi (Nov 24–30, 2026):** [`/oahu/`](./oahu/) → `https://sbandal.github.io/travel/oahu/`

## Structure
```text
travel/
├── index.html      # Landing hub listing all trips
└── oahu/           # Oʻahu Thanksgiving Week Trip Planner
    ├── index.html
    ├── styles.css
    ├── data.js
    ├── app.js
    └── assets/
```

To add a new trip in the future, create a new subfolder (e.g. `travel/japan/index.html`) and add a card in the root `index.html`.
